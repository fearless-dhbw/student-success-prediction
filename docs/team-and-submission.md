Each owner commits their own work, documents their contributions in GitHub and the slides, and prepares to explain their implementation and decisions in the individual viva.

## Submission checklist

- [ ] Problem and data pipeline (15 marks). Research question, data provenance, cleaning, feature engineering, and EDA.
- [ ] Model progression (20 marks). Baseline, tuned ensemble, feature selection, fair comparison, and diagnostics.
- [ ] Evaluation and visuals (15 marks). Metrics for each configuration, confusion matrix, and discussion of errors.
- [ ] Live deployment (15 marks). Public link opens in a signed-out session and returns predictions.
- [ ] Ownership and viva (15 marks). Contributors and responsibilities documented in GitHub and slides.
- [ ] GitHub contains clean code, the preprocessed dataset, and a structured README with reproducible commands.
- [ ] Deck has at most 15 slides excluding title and thank-you slides. Presentation, demo, and individual Q&A fit in 12 minutes.
